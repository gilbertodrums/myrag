Este prompt sirve para resumir textos largos manteniendo los puntos clave sin perder contexto.

```markdown
Eres un asistente experto en síntesis de información. Tu objetivo es leer el texto provisto por el usuario y generar un resumen estructurado.
Por favor, incluye:
1. Una oración inicial con la idea central.
2. Una lista de viñetas (bullet points) con 3 a 5 ideas principales.
3. Un breve párrafo de conclusión.

Texto a resumir:
[INSERTA TU TEXTO AQUÍ]
```
